Daftar Fitur :

1. Fitur Login (Masuk)

Fitur login digunakan sebagai halaman awal aplikasi. Pengguna dapat menekan tombol Masuk untuk masuk ke halaman utama yang menampilkan informasi profil mahasiswa. Pada implementasi saat ini, login masih berupa simulasi dan belum menggunakan autentikasi akun.

2. Fitur Profil Mahasiswa

Fitur ini digunakan untuk menampilkan informasi utama mahasiswa, meliputi:
- Foto profil.
- Nama lengkap.
- Nomor Induk Mahasiswa (NIM).
- Program studi.
- Kelas.
3. Fitur Informasi Tentang Saya

Fitur ini menampilkan deskripsi singkat mengenai mahasiswa, seperti ketertarikan terhadap teknologi, pengembangan aplikasi, dan kegiatan pembelajaran.

4. Fitur Informasi Kontak

Fitur ini digunakan untuk menampilkan informasi kontak mahasiswa, meliputi:
- Alamat email.
- Nomor handphone.
- Username GitHub.
5. Fitur Edit Profil

Fitur edit profil memungkinkan pengguna mengubah informasi pribadi yang ditampilkan pada halaman profil. Data yang dapat diubah meliputi nama, NIM, program studi, kelas, bio, email, nomor HP, dan username GitHub.

6. Fitur Validasi Form

Fitur validasi digunakan untuk memastikan data yang dimasukkan sesuai dengan ketentuan. Contohnya, nama wajib diisi, email harus memiliki format yang valid, dan nomor HP harus terdiri dari 10–13 digit angka.

7. Fitur Simpan Perubahan Profil

Fitur ini berfungsi menyimpan perubahan informasi profil setelah pengguna selesai melakukan pengeditan. Data yang diperbarui akan langsung ditampilkan pada halaman profil selama aplikasi berjalan.

8. Fitur Keahlian (Skills)

Fitur ini menampilkan kemampuan dan keterampilan mahasiswa yang meliputi:
- Pengembangan Aplikasi menggunakan Flutter dan Dart.
- Figma Design untuk desain dan prototyping.
- Problem Solving untuk menganalisis dan menyelesaikan masalah.
9. Fitur Hobi dan Minat

Fitur ini menampilkan aktivitas dan minat mahasiswa, seperti:
- Badminton.
- Billiard.
- Belajar Teknologi.
Setiap hobi dilengkapi dengan deskripsi singkat.

10. Fitur Riwayat Pendidikan

Fitur ini menampilkan informasi riwayat pendidikan mahasiswa, mulai dari perguruan tinggi, sekolah menengah atas, hingga sekolah menengah pertama.

11. Fitur Navigasi Menu

Fitur navigasi digunakan untuk memudahkan pengguna berpindah halaman dalam aplikasi. Terdapat dua menu utama, yaitu:
- Profil: menampilkan informasi pribadi mahasiswa.
- Tentang Saya: menampilkan keahlian, hobi, dan riwayat pendidikan.

12. Fitur Drawer Menu

Drawer merupakan menu samping yang dapat dibuka untuk mengakses navigasi Profil, Tentang Saya, pengaturan tema, dan tombol Keluar.

13. Fitur Mode Gelap (Dark Mode)

Fitur ini memungkinkan pengguna mengubah tampilan aplikasi dari mode terang (Light Mode) menjadi mode gelap (Dark Mode) atau sebaliknya sesuai kenyamanan pengguna.

14. Fitur Logout (Keluar)

Fitur logout digunakan untuk keluar dari halaman utama dan kembali ke halaman login. Dengan demikian, pengguna dapat mengakhiri sesi penggunaan aplikasi.
